# Curated Sources Library

<overview>
Quality niche sources organized by category. These feeds are:
- Consistently active (1+ posts/month)
- High signal-to-noise ratio (original analysis, not aggregation)
- Established reputation (2+ years active)
- Niche expertise (focused domain)
- Lesser known (not mainstream media)
</overview>

<selection_criteria>
## Selection Criteria

Feeds included here meet:

**Consistency**: 1+ posts/month (or established pattern)
**Quality**: Original analysis, research, or reporting
**Reputation**: 2+ years active, recognized in field
**Focus**: Niche expertise, not general aggregation
**Accessibility**: Not mainstream (NYT, WSJ, etc.)

**User can extend this library** by adding their own discoveries under each category.
</selection_criteria>

<usage_notes>
## Usage Notes

When recommending sources:
1. Check user's existing feed list
2. Filter out domains already present
3. Match recommendations to user's categories
4. Prioritize complementary perspectives
5. Include 3-5 recommendations per category
6. Provide context (why this source, frequency, history)

Users will grow this list over time with their own discoveries.
</usage_notes>
